Question 2: Is It Safe?
Most safety failures are about access, not hackers. Look for three leaks:
What you send out
Data leaving your system in every 
prompt - often far more than the task 
needs
What's left lying around
Logs, caches, and stored results that 
hold sensitive data longer than 
necessary
Who can do what
Permissions that give the agent more 
power than its task requires

A script fires 20 scoring requests simultaneously. Each is

Volume exposes failures no test set will.

The provider's "too busy" error, returned under load
Meet Portkey: The Toll 
Booth for Your AI Calls
One door to all models
Route calls to any provider without changing your code
Retries + fallbacks
Automatic recovery when a provider is slow or down
Rate limits + budget caps
Set a spend ceiling before the bill arrives
Wait, Then Try Again
Wait 4s + jitter → Attempt 4
Wait 2s → Attempt 3
Wait 1s → Attempt 2
Attempt 1 (Immediate)
Retry the same 20 requests: wait 1 s, 
then 2, then 4, with a small random 
wobble - up to 4 tries. If it still fails, mark 
it "queued", never "lost".
Use Claude Code to write it, or use 
Portkey's built-in retry setting.
Before
11 of 20 succeed
After
20 of 20 succeed, a bit slower
Retries Fix Hiccups. A Queue Fixes Floods.
When 50 applications arrive in a minute, retrying all 50 hits the same wall again.
Queue it
Save each application as "pending" and reply "received". A scheduled job 
scores 5 a minute. Nothing is lost, and nothing overloads the provider.
Cache it
Same application, same prompt version? Reuse the stored answer. No 
second AI call, no second bill.

You Operate It?

The Worst Failures Don't Announce Themselves
Nothing crashed. No error appeared. The answers were simply wrong - and only reading real runs revealed it.
You can't fix what you can't see.
Silent failure
Wrong output with a green status is the hardest failure to catch

Four Levers to Control Cost
Send less
Trim every prompt to what the step actually needs
Remember answers
Cache identical inputs so you don't pay twice
Cap the spend
Set a Portkey budget limit before the bill arrives
Use cheaper models
Right-size the model to the difficulty of each step
Remember to set the limit in advance.
