--- slide 3
Start here: what is an agent?
3
MESA Term 2 | Advanced AI | S5: Split It

A model
Reads text, writes text. It cannot look anything up or change anything.

An agent
A model plus three things: an instruction, tools, and a loop.
Instruction: the job description.
Tools: Python functions it may ask for.
Loop: ask for a tool, read the result, repeat or answer.

Dhruva example
Ira asks: should we take a call with FactoryDesk?
The agent asks for score_application, gets fit 7.5, and replies ADVANCE TO CALL.


i
A model talks. An agent talks and does things, because your code does the job and hands back the answer.

Three ways to arrange agents: line, side by side, loop
12
MESA Term 2 | Advanced AI | S5: Split It
Workflow agent | The picture | Use it when | Dhruva example
Sequential | An assembly line: A finishes, then B starts | The steps are fixed and in order | Read the application, then score it, then write the note
Parallel | Two clerks working at once | The jobs do not depend on each other | Score all six applications at the same time
Loop | Draft, check, redo until it passes, or give up after a few rounds | A result needs checking before it goes out | S6: a maker writes the note, a checker verifies it
Delegation (today) | A front desk that asks the right department | The model should decide who to ask | Ira asks the front agent; it asks the analyst or ops


i
Sequential, parallel and loop run in a fixed pattern you write. Delegation lets the model choose. Fixed is cheaper and more predictable.

Reading the event trace: one question, four events
13
MESA Term 2 | Advanced AI | S5: Split It
# | Event in the dev UI | What it means | Model call?
1 | User: Should we take a call with FactoryDesk? | The question comes in | No
2 | Agent: function call score_application(app_id='A03') | The consultant writes a slip for the slot | Yes (call 1)

4 | Agent: Recommendation: ADVANCE TO CALL. Fit 7.5. | The consultant writes the answer | Yes (call 2)

Why count model calls
Every model call costs money and time. One lookup takes two calls: one to choose a tool, one to write the answer. A shortlist of six takes about eight. Today you measure this.

A trace is the receipt. Read it before you trust the answer.

The split: an interaction agent, an analyst and an ops agent
18
MESA Term 2 | Advanced AI | S5: Split It
Agent | The picture | Tools it holds | Why it is separate
Partner assistant (interaction) | The front desk: talks to Ira, never looks anything up | None; asks the other two | Owns the conversation and the tone
Analyst | The researcher: reads and scores | list, get, score (all read only) | Can be tested and changed alone; cannot change anything
Ops | The clerk who opens tickets | escalate_to_analyst (changes something) | The only agent with write access: easy to review and restrict

The cost
Every hop is another model call. One question now goes: front agent, analyst, tools, analyst, front agent. We measure how many extra calls and how many extra seconds, and whether the answers got better.


i
Split when the parts have different owners, permissions or prompts. Do not split just because it looks tidy.

--- slide 22
When would you NOT split? Write the verdict
22
MESA Term 2 | Advanced AI | S5: Split It

Reasons to split
Different owners: the ops team runs its own agent.
Different permissions: only one agent can change something.
The single prompt has grown past what the model follows.
Different models for different jobs, to save cost.

Reasons not to
The pass rate did not move.
Every question now costs about twice the calls and time.
Small team, four tools, one owner.
More agents mean more places for a bug to hide.

Verdict (5 lines):
v1 passed __ of 5 with __ model calls and __ s. v2 passed __ of 5 with __ calls and __ s.
With four tools and one owner, the split [did / did not] earn its cost because ___.
I would split only if ___ (an owner, a permission, or a prompt that has grown).


i
Example: 'With four tools and one owner, the split did not earn its cost.' Yours must use your own numbers.

    instruction="Use the tools for every fact ... If a tool errors, say so, do not retry.",
    tools=[list_applications, get_application,
           score_application, escalate_to_analyst],   # each function is a job card

Reference: if something fails
29
MESA Term 2 | Advanced AI | S5: Split It
You see | Do this
No module named google | The environment is not active. Run the activate line again
API key not valid, or 403 | The key is wrong or missing. Paste it after GOOGLE_API_KEY= with no quotes or spaces
429 or RESOURCE_EXHAUSTED | Free-tier limit (per minute or per day). Use --rpm 5, wait a minute, or share a neighbour's screen; a daily limit resets after hours
model not found | Set DHRUVA_MODEL in .env to another model name your key can use
adk web shows no agents | Run it from the S5 folder, and check each agent folder has an __init__.py
A scenario fails but the answer looks right | The reply lacks the exact 'Recommendation:' line. Fix the instruction, not the checker
Scenario 5 does not say already open | Scenario 4 must run first in the same run. Run the five together

Reference: only plug in code you have read
30
MESA Term 2 | Advanced AI | S5: Split It

What to remember from S4
A server, or an agent file, hands your assistant text and tools.
Hidden instructions in that text are prompt injection: a forged memo in the in-tray.
Prefer read-only tools. Make any tool that changes something ask a person first.

In S5
Ops is the only agent that can change anything.
The instruction says escalate only when asked.
The ticket tool is safe to call twice.
